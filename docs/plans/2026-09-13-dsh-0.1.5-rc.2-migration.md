# dsh 0.1.5-rc.1 → 0.1.5-rc.2 migration audit (dsh-mineru)

- 日期：2026-09-13
- 走廊：`dsh-v0.1.5-rc.1` → `dsh-v0.1.5-rc.2`
- 卡片来源：oh-my-dsh/dsh-plugin-upgrade-skill
  `skills/plugin-upgrade/references/v0.1.5-rc.2.md`（RC2-01…06）
- 结论：**本插件零源码改动**（升级卡全部非命中或 optional），生产树升级后复跑三件套抽查即可。

## 升级卡摘要

| 卡 | 类型 | 内容 |
|---|---|---|
| RC2-01 | breaking | feedback 注入契约：`toggle`→`retract`、`openDialog(messageId, rating)`、`acknowledge()` 移除、`MessageFeedbackToggleResult` 不再导出 |
| RC2-02 | behavior | 两种评分都改为弹窗确认；提交失败转 6s 警告 toast |
| RC2-03 | behavior | `FileTypeIcon` 48 个代码分类图标换设计导出 artwork |
| RC2-04 | behavior | 回合尾动作条与文件区 20/16/20px 间距契约 |
| RC2-05 | behavior | `service-stability` 文案改字，key 不变 |
| RC2-06 | info | Host 面零变更（334 变更文件中 272 个仅版本号） |

## 本插件触点审计

| 卡 | 结果 | 证据 |
|---|---|---|
| RC2-01/02 | 非命中 | `lib/client.js` 不注入 `dsh-client-ui-message-feedback` 相关服务，无 feedback 契约引用 |
| RC2-03 | 非命中 | 无 `FileTypeIcon` / `CodeFileIcon` / `dsh-code-icon-*` 引用 |
| RC2-04 | 非命中 | 不贡献 `conversation.chat.turnTail` 槽位 |
| RC2-05 | 非命中 | 无 `service-stability` 分类文案复制 |
| RC2-06 | 免疫依据 | Host 面零行为变更；6 个 `@deepseek-ai/dsh-*` peer 均为 `^0.1.5-rc.1`，可满足 rc.2 |

本插件实际触点（每次升级按此清单核对）：

- Host 面：`ctx.settings.register('mineru', …)`、`ctx.tools.register`、
  `ctx.skills.register`、`ctx.credentials.resolve/describe`、`credentialRef`、
  `defineTool`、`SettingsConflictError`、`ctx.inject(['webServer'], …)` 与
  `webServer.register`；
- Client 面：`window.__ModuleLoader__.load({ id, factory })`、注入服务
  `['slots', 'connection', 'sessions', 'conversation', 'locale']`、槽位
  `settings.plugins.tab` / `tool.call.toolview`；
- 主题 token：强调色只用 `--dsw-alias-brand-primary-new-colorprimary-new-color`
  （禁止把 `--dsw-alias-brand-primary` 当背景/彩色用，平台把它绑定为前景色）。

## 升级核对流程（每次 dsh 发版复用）

1. 从 oh-my-dsh/dsh-plugin-upgrade-skill 拉取对应版本的 references 卡片；
2. 按上方触点清单逐卡比对（`grep -rn` 扫描 `lib/`，排除注释）；
3. 非命中卡在 docs/plans 里留档（格式同本文件）；
4. 命中卡先改代码，再 `node --check lib/*.js && npm test && npm pack --dry-run`；
5. 涉及 client 面的改动必须确认打包产物仍以 `window.__ModuleLoader__.load` 注册。
